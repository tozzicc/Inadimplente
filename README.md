# 🇺🇸 English

## 📌 About the Project

**FinTrack Pro | Inadimplente** is a full-stack web application developed to manage and monitor financial delinquency through a centralized dashboard.

The system provides an organized view of debtors and outstanding payments, allowing financial information to be registered, updated, searched and monitored through a practical web interface.

The project combines a modern React frontend with a Node.js API, Prisma ORM and PostgreSQL database, demonstrating the development of a complete business-oriented web application.

---

## ✨ Main Features

- Financial delinquency dashboard
- Debtor registration and management
- Create, edit and delete records
- Search by name or document
- Outstanding payment tracking
- Overdue payment monitoring
- Payment status management
- Financial summary indicators
- Active debtor monitoring
- Data visualization through charts
- Responsive web interface
- Backend API integration
- Persistent database storage

---

## 📊 Financial Dashboard

The dashboard provides a centralized overview of the delinquency portfolio.

Information presented by the application includes:

- Total overdue amount
- Total pending amount
- Number of active debtors
- Financial indicators
- Visual charts
- Debtor records
- Payment status

The objective is to make financial monitoring faster and easier through a single interface.

---

## 👥 Debtor Management

Each record can contain information such as:

- Name
- Document
- Amount
- Due date
- Payment status

Supported statuses include:

- `Paid`
- `Pending`
- `Overdue`

The system allows records to be created, edited and deleted according to the user's needs.

---

## 🔎 Search & Monitoring

The application provides tools to quickly locate debtor information.

Users can search records using:

- Name
- Document

This makes it easier to monitor individual records without manually browsing the complete database.

# 🇧🇷 Português

## 📌 Sobre o Projeto

**FinTrack Pro | Inadimplente** é uma aplicação web full-stack desenvolvida para gerenciar e acompanhar a inadimplência financeira por meio de um dashboard centralizado.

O sistema oferece uma visão organizada dos devedores e valores pendentes, permitindo cadastrar, atualizar, pesquisar e acompanhar informações financeiras através de uma interface web prática.

O projeto combina um frontend moderno desenvolvido em React com uma API Node.js, Prisma ORM e banco de dados PostgreSQL, demonstrando o desenvolvimento de uma aplicação web completa voltada para uma necessidade de negócio.

---

## ✨ Principais Funcionalidades

- Dashboard de inadimplência financeira
- Cadastro e gerenciamento de devedores
- Inclusão, edição e exclusão de registros
- Pesquisa por nome ou documento
- Acompanhamento de valores pendentes
- Monitoramento de valores em atraso
- Controle de status dos pagamentos
- Indicadores financeiros
- Acompanhamento de devedores ativos
- Visualização de dados através de gráficos
- Interface web responsiva
- Integração com API backend
- Persistência dos dados em banco de dados

## 📊 Dashboard Financeiro

O dashboard oferece uma visão centralizada da carteira de inadimplência.

Entre as informações apresentadas pela aplicação estão:

- Valor total em atraso
- Valor total pendente
- Quantidade de devedores ativos
- Indicadores financeiros
- Gráficos
- Registros de inadimplentes
- Status dos pagamentos

O objetivo é tornar o acompanhamento financeiro mais rápido e simples através de uma única interface.
